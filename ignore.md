# **4. What I would NOT install**

Avoid these for this project:

- Flutter and Dart skills.
- React Native and Expo skills.
- SwiftUI and iOS skills.
- Next.js and React frontend skills.
- AWS deployment skills.
- Kubernetes and Docker orchestration skills.
- AI model training skills.
- Video generation skills.

They add no immediate value to your native Android MVP.
